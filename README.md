# isaiasdiaz.com

Sitio personal y comercial de Isaías Díaz. Next.js, exportación estática, selector de tema e idiomas ES/EN/PT.

## Desarrollo local

```bash
npm install
npm run dev
npm run build
```

## Cloudflare Pages

- Framework preset: Next.js (Static HTML Export), o configuración personalizada.
- Build command: `npm run build`
- Build output directory: `out`
- Production branch: `main`

El sitio es estático: contacto y blog son secciones de presentación por ahora, sin backend ni formulario operativo. No incluyas secretos en el repositorio.
